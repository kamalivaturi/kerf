Install in three steps

  1. Install Python 3.10+ and FFmpeg.
  2. Download and unzip the latest release, then run pip install -e ".[ai]" in that folder.
  3. Premiere: double-click kerf-premiere-*.ccx. Resolve: run install\install-resolve.ps1.

No editor? Start the engine and open the web app:

python -m kerf serve
# then open http://127.0.0.1:7878/app/

Questions

Is it really free?

Yes. MIT licensed. AI providers and stock services you choose to connect bill you directly.

Does my footage get uploaded?

No. Transcription, silence detection, face tracking and rendering run locally. Only the features you connect to an online service (AI prompt edits, ElevenLabs, Pexels, downloads) talk to the internet.

Does it change my original sequence?

Never. Each run creates a new sequence or timeline you can compare, keep or delete.

Which editors are supported?

Premiere Pro 25.6+ through a modern UXP plugin, DaVinci Resolve 18.6+ (Free and Studio) through its Scripts menu, and anything that imports FCP7 XML via the standalone app.
